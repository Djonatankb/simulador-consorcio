# Paleta de cores — Liga Vitória Corretora de Seguros

Valores oficiais extraídos do manual da marca (`Apresentacao-Logotipo-Liga-Vitoria.pdf`).

## Cores institucionais

### Azul (principal)
- HEX: `#00499A`
- RGB: 0 73 154
- CMYK: 100 75 0 0
- Pantone: 2945 C

### Azul-marinho (secundária)
- HEX: `#211451`
- RGB: 33 20 81
- CMYK: 100 100 0 50
- Pantone: 274 C

## Uso na LP
- O **azul-marinho `#211451`** substitui o vermelho placeholder (`--brand`) do protótipo como cor principal de marca.
- O **azul `#00499A`** entra como cor de destaque / links / detalhes.
- Para os blocos de fundo escuro da LP, usar `#211451` como fundo e o logo na versão **branca**.
- O vermelho Bradesco (seguradora) entra só pontualmente como selo, sem competir com o azul da Liga Vitória.

> Os valores HEX são a referência para o CSS. Os arquivos de logo em `01-logo-corretora/web/`
> já foram normalizados para esses dois HEX.
